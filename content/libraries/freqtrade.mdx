## Por que escolher

- **Bot OSS mais popular** para trading de cripto — comunidade gigante, exemplos de estratégia em abundância.
- **Backtest + hyperopt** integrados — testa estratégia em histórico, otimiza hiperparâmetros via Optuna.
- **Telegram bot** para acompanhar ordens em tempo real e dar comandos remotos.
- **Suporta os exchanges principais** (Binance, Coinbase Pro, Kraken, Bybit, OKX) via CCXT.

## Cuidados

- **Trading com bot é risco real** — usuário inexperiente perde dinheiro. Comece em dry-run + paper trading.
- Estratégia ruim em backtest é dinheiro a menos em produção. Validação out-of-sample é obrigatória.
- Manutenção contínua — exchange API muda, regulamentação muda, mercado muda.

## Alternativas

- **Hummingbot** se você quer market-making específico.
- **TradingAgents** (OSS recente) se quer agente LLM-powered fazendo decisões.
- **AI-Trader, Backtrader, Zipline** se quer Python puro para pesquisa quantitativa.
