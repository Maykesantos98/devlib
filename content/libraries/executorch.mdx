## Por que escolher

- **Inference offline** — sem latência de rede, privacidade preservada.
- **Backends acelerados** (Core ML, MPS, Vulkan, XNNPACK).
- **`react-native-executorch`** dá hooks React diretos.

## Cuidados

- Tamanho do bundle: modelo de 4B params = ~2GB no app. Use quantização 4-bit ou modelos < 1B.
- API ainda em maturação — quebras possíveis entre versões. Pin a versão.
