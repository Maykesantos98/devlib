## Por que escolher

- **BaaS open source** — Auth, DB, Storage, Functions, Realtime, Messaging em um stack próprio.
- **Self-host real** via Docker Compose, mantido ativo, comunidade grande.
- **SDKs em todas as linguagens populares** — Flutter, Swift, Kotlin, Python, Node, Web. Bom para apps mobile.
- **Functions** rodam em Deno, Node, Python, PHP, Ruby — flexibilidade alta.

## Cuidados

- Storage interno é MariaDB — não é Postgres. Migrações e features avançadas são menos ricas.
- Realtime via WebSocket, mas escala horizontal exige Redis + tuning.
- Cloud hosted é mais novo que Supabase; tier free menos generoso em uso intenso.

## Alternativas

- **Supabase** se você prefere Postgres real e cloud-first.
- **Firebase** se você quer Google ecosystem maduro.
- **PocketBase** se você quer single-binary (ainda mais simples para self-host).
