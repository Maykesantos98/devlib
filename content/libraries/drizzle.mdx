## Por que escolher

- **Sintaxe próxima de SQL** — você entende exatamente a query gerada.
- **Sem runtime overhead** — gera SQL no build, dispatcher minúsculo em runtime.
- **Edge-compatible** — funciona em Cloudflare Workers, Vercel Edge, Bun.
- **Migrations gerenciadas** — `drizzle-kit generate` + `migrate`, sem mágica.

## Drizzle vs Prisma

| | Drizzle | Prisma |
|---|---|---|
| Sintaxe | Próxima do SQL | DSL própria |
| Edge | ✅ nativo | ⚠️ via Accelerate |
| Type safety | Inferida | Gerada |
| Bundle | < 10kb | ~200kb |

Use Drizzle quando edge importa, SQL importa, ou bundle importa.
