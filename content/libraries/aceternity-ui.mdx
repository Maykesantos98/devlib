## Por que escolher

- **Hero sections + backgrounds animados** prontos — efeitos que costumavam levar dias.
- **Framer Motion + Tailwind** — stack moderna, integra com qualquer app React.
- **Copy-paste** — você é dono do código. Edição livre.
- **Visual signature forte** — identidade premium em landings.

## Cuidados

- Muitos efeitos custosos em GPU — teste em mobile antes de produção.
- Pro tier ($$) — para acesso completo. Free cobre muito mas não tudo.
- Não é sistema de design — para app full, combine com shadcn ou HeroUI como base.

## Alternativas

- **Magic UI** se quer biblioteca similar OSS-only.
- **shadcn/ui** se quer primitives + sistema completo.
- **Framer** (no-code) se prefere editor visual.
