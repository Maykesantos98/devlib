## Por que escolher

- **Você é dono do código** — sem `node_modules` versão lock-in, edite à vontade.
- **Radix + Tailwind v4** — a11y resolvida no underlying lib.
- **CLI `shadcn add button`** instala dependências + arquivos.
- **Tema via CSS variables** — três temas no DEVLIB v04 são exatamente esse padrão.

## Cuidados

- Atualizar componente significa re-rodar `add` e revisar diff. Sem upgrade automático.
- Não é design system completo — só primitives. Combine com Magic UI ou Aceternity para hero/marketing.
