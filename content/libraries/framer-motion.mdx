## Por que escolher

- **`<motion.div animate={...}>`** — animação como prop.
- **Layout animations** — `layout` prop faz FLIP automaticamente.
- **Spring physics** — feel natural, sem decorar curvas cubic-bezier.
- **`useScroll`, `useTransform`** para parallax sem lib extra.

## Cuidados

- Bundle ~50kb — não é trivial. Para uso minimal, use CSS animations.
- Animar `width`/`height`/`top`/`left` é o caminho fácil para 5fps. Sempre `transform` + `opacity`.
- Respeite `prefers-reduced-motion` com `MotionConfig`.
