## Por que escolher

- **Componentes prontos para marketing** — animated beam, particles, marquee infinito.
- **Compatível com shadcn** — usa Tailwind + Framer Motion, mesmas conventions.
- **Copy-paste** ou via CLI, você é dono do código.
- **Acabamento "feito por designer"** para devs sem time de design.

## Cuidados

- Vários efeitos custosos no GPU — teste em mobile antes de produção.
- Use seletivamente: 2-3 componentes "wow" por página, não 10.
