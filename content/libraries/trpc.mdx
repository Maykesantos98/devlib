## Por que escolher

- **Sem schema duplicado** — define `query`/`mutation` no server, client tem autocomplete completo. Adeus OpenAPI manual.
- **Adapters** para Next, Express, Fastify, AWS Lambda, Cloudflare Workers.
- **TanStack Query integrado** — caching, refetch, mutations. UX dura sem React Query manual.
- **Server Components compatíveis** desde Next 14 via `createTRPCContext`.

## Cuidados

- **TS-only** — não é REST nem GraphQL. Se você tem clients em Python/Go, precisa de gateway REST ou OpenAPI generator.
- **Bundle do client** vai junto com schema do server. Em apps grandes, prefira lazy import por router.
- **Não é GraphQL** — se você precisa de queries flexíveis com selection ad-hoc, é a ferramenta errada.

## Alternativas

- **Hono RPC** se você usa Hono e quer leve.
- **tsoa + OpenAPI** se você precisa de REST clássico tipado.
- **GraphQL** se queries flexíveis são o caso de uso real.
