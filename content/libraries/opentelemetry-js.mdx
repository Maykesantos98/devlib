## Por que escolher

- **Padrão vendor-neutral** — escreve instrumentação uma vez, envia para Datadog, Honeycomb, Tempo, LangSmith, Jaeger, qualquer um.
- **Auto-instrumentation** para Express, Fastify, HTTP, fetch, Postgres, Redis, Mongo. Setup em 5 linhas.
- **Aceito por todas plataformas** — AI SDK exporta telemetry via OTel, LangSmith ingere automaticamente.
- **Open standard** sob CNCF — não vai sumir nem ser quebrado por vendor.

## Cuidados

- Curva inicial densa — propagator, context, baggage, instrumentation library. Comece pelo auto-instrumentation.
- Performance: sampling agressivo é obrigatório em produção. 100% trace = 30% CPU overhead em hot path.
- Stack de export (collector) pode virar peça extra para manter — Datadog/Honeycomb simplificam.

## Alternativas

- **Sentry SDK direto** se você só quer error + performance, sem trace distribuído.
- **PostHog instrumentation** para product analytics, não APM.
