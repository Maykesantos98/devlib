## Por que escolher

- **1000+ componentes** extendem shadcn/ui — kanbans, data grids, file uploads, complex forms.
- **Variações Base UI e Radix** — escolha o primitive que prefere por componente.
- **Copy-paste compatible** com shadcn — mesmo workflow.
- **Bom para apps internos** — admin panels, dashboards, ferramentas internas.

## Cuidados

- Catálogo grande significa qualidade variável — alguns componentes mais maduros que outros.
- Para landings hero impact, prefira Magic UI/Aceternity.
- Verifique a11y de componentes específicos antes de produção crítica.

## Alternativas

- **Shadcn Blocks** — blocks oficiais shadcn, menos quantidade mas qualidade homogênea.
- **Tremor** se foco é dashboards de analytics.
