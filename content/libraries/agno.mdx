## Por que escolher

- **Multimodal por padrão** — text, image, audio. Frameworks que tratam só texto ficam apertados aqui.
- **Multi-agent compositional** — orquestra times de agentes com role/responsibility claros.
- **Memory + RAG embutidos** — vector stores, knowledge bases, session memory.
- **Playground UI** para debugar agentes sem escrever frontend custom.

## Cuidados

- Python — se time é TS, prefira Mastra ou AI SDK.
- API ainda em maturação; releases trazem breaks ocasionais. Pin a versão.
- Para single-agent simples, AI SDK ou Anthropic SDK direto são mais leves.

## Alternativas

- **CrewAI** se você quer role-based multi-agent com mais opinião sobre dynamics.
- **LangGraph** se quer grafo de decisão explícito.
- **PydanticAI** se quer type-safety Python com Pydantic schemas.
