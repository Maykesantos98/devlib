## Por que escolher

- **Pydantic-first** — schemas que você já tem viram tool inputs/outputs validados.
- **Type-safe** — `Agent[OutputType]` dá IDE autocomplete em respostas. Refactor friendly.
- **Multi-provider** — Anthropic, OpenAI, Gemini, Ollama, Groq.
- **Streaming + tool calling** com semantics claros — pouco mágica.

## Cuidados

- Comunidade jovem — menos tutoriais que LangGraph/CrewAI.
- Para multi-agent complex, framework é menos opinionado — você monta a orquestração.
- Python específico — sem versão TS.

## Alternativas

- **AI SDK** (TypeScript) se você quer mesma filosofia em TS.
- **Agno** se quer multimodal forte.
- **Pydantic Logfire** para observability integrada.
