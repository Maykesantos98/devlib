## Por que escolher

- **Engine própria** — renderiza tudo via Skia/Impeller. UI idêntica iOS/Android/Web/Desktop sem surprise.
- **Hot reload < 1s** mesmo em apps grandes. DX top em mobile.
- **Animação built-in** — `AnimatedContainer`, implicit animations, motion natural sem libs externas.
- **Material 3 + Cupertino** seguem design system oficial Google/Apple.
- **LiteRT-LM (2026)** permite Gemini Nano on-device em apps Flutter.

## Cuidados

- **Dart** — linguagem própria, mas concisa e familiar para quem vem de TS/Java.
- **App size começa em ~10MB** (vs ~5MB Swift puro). Para empresas com restrição forte de tamanho, considere.
- **Integração com modules nativos** menos polida que React Native — você escreve channel handlers manualmente.

## Alternativas

- **React Native + Expo** se time já é forte em React/web.
- **Native Swift/Kotlin** se você quer máxima performance + integração com hardware.
