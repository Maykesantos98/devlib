## Por que escolher

- **Headless** — zero opinião sobre estilo, combina com qualquer design system.
- **Type-safe** — colunas tipadas pelo shape dos dados.
- **Virtualização** plug-and-play com `@tanstack/react-virtual` (linhas 100k+).
- **Server-side** mode para paginação remota e infinito.

## Cuidados

- Curva de aprendizado real — não é "table que renderiza dados".
- Para tabelas simples, `<table>` puro + Tailwind resolve.
