## Por que escolher

- **Engine por trás do Ollama, LM Studio, Jan e quase todo runner local** — referência da indústria.
- **GGUF format** — comunidade gigantesca de modelos pré-quantizados em Hugging Face.
- **Roda em hardware modesto** — quantização 4-bit faz Llama 3.1 8B rodar em laptop sem GPU dedicada.
- **Acelera em CUDA, Metal, ROCm, Vulkan** — escolhe o backend conforme hardware automaticamente.

## Cuidados

- Não tem UI — você precisa de wrapper (Ollama, LM Studio) ou interage via CLI.
- Setup direto exige compilar (ou baixar pre-build). Para usuário final, prefira Ollama.
- Performance específica varia muito por modelo + quantização + hardware. Benchmark é obrigatório.

## Alternativas

- **MLC LLM** se quer mobile + web + desktop com mesma engine.
- **ExecuTorch** para mobile production-ready em RN/iOS/Android.
- **vLLM** se você está em servidor GPU e quer throughput máximo.
