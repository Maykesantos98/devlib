## Por que escolher

- **Você é dono do código** — sem `node_modules`, sem version-lock. Cole e edite.
- **Radix Primitives** debaixo dá a11y resolvida — focus trap, ARIA, keyboard nav.
- **CLI `shadcn add button card`** instala dependências e arquivos juntos.
- **Tema via CSS variables** — funciona com qualquer paleta. Theming visual sem complexity.

## Cuidados

- Atualização não é automática. Cada componente novo do upstream exige re-rodar `add` e revisar diff.
- Não é design system completo — só primitives. Combine com Magic UI ou Aceternity para marketing.
- Requer Tailwind — em projetos sem, é trabalho extra.

## Alternativas

- **HeroUI / Magic UI / Aceternity** se quer componentes mais estilizados.
- **Radix Themes** se quer design pronto e sem editar.
