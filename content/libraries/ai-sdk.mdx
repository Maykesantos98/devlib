## Por que escolher

- **Provider-agnostic** via strings `"anthropic/claude-sonnet-4-5"` (com AI Gateway).
- **`generateText`, `streamText`, `generateObject`, `streamObject`** — APIs simétricas.
- **Tool calling** com Zod schema validado.
- **`experimental_telemetry`** para LangSmith / Vercel Observability.

## Padrão para agentes

```ts
const { object } = await generateObject({
  model: 'anthropic/claude-sonnet-4-5',
  schema: ProductSchema,
  prompt: 'Gere um produto...',
});
```
