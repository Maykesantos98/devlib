## Por que escolher

- **Workflow git-centric** — cada edição vira commit semântico. Histórico legível por humanos depois.
- **Repository map** mantém entendimento do codebase entre sessões via tree-sitter.
- **Multi-provider** — Anthropic, OpenAI, OpenRouter, Ollama. Custo controlável.
- **Leaderboard transparente** mostra performance por modelo em benchmarks reais.

## Cuidados

- **Terminal-puro** — sem UI gráfica. Para times que preferem GUI/IDE, prefira Cline/Cursor.
- **Skills/MCP** menos polidos que Claude Code. Custom tooling exige mais manual.
- **Memory** limitado — para sessões longas, dependa de bons commit messages como memória.

## Alternativas

- **Claude Code** se Anthropic + terminal + skills é seu caminho.
- **OpenHands** se quer sandbox isolado e UI web.
