## Por que escolher

- **Sucessor do NextUI** — refinado, ativo, com identidade visual coerente.
- **React Aria por baixo** — a11y de primeira classe (Adobe).
- **40+ componentes** — Button, Modal, Table, Autocomplete, DatePicker. Stack quase completa.
- **Theming Tailwind v4** — variáveis CSS para customizar tudo.

## Cuidados

- Componentes vêm como package — não é copy-paste. Atualização vs lock-in trade-off.
- Bundle size se você usar tudo é ~150kb gzipped. Tree-shake é OK mas precisa atenção.
- Para projetos com design system muito específico, prefira shadcn (você é dono).

## Alternativas

- **shadcn/ui** se quer ownership total do código.
- **Mantine** se quer alternativa madura com mais utilities.
- **Park UI** se quer Tailwind + Ark UI primitives.
