## Setup em 7 passos

### 1. Bootstrap

```bash
npx create-next-app@latest meu-dash --typescript --tailwind --app
npx shadcn@latest init
npx shadcn@latest add card tabs select dropdown-menu skeleton
npm install drizzle-orm @neondatabase/serverless @tanstack/react-table recharts @tremor/react
```

### 2. Queries com Drizzle

```ts
// db/queries/dashboard.ts
import 'server-only';
import { sql } from 'drizzle-orm';
import { db } from '../client';
import { orders } from '../schema';

export async function revenueByDay(days = 30) {
  return db
    .select({
      date: sql<string>`date_trunc('day', ${orders.createdAt})`.as('date'),
      total: sql<number>`sum(${orders.amount})`.as('total'),
    })
    .from(orders)
    .where(sql`${orders.createdAt} > now() - interval '${days} days'`)
    .groupBy(sql`date_trunc('day', ${orders.createdAt})`);
}
```

### 3. KPI Cards (Server Component)

```tsx
// components/kpi-card.tsx
export async function KpiCard({ title, query }: Props) {
  const value = await query();
  return (

      <CardHeader>
```

## Alternativas

- **Tableau / Metabase** se a equipe não tem dev disponível. UI menos polida, ROI rápido.
- **ECharts** se dataset > 100k pontos.
- **ClickHouse** no lugar de Postgres para analytics puro — 100x mais rápido em queries OLAP.
- **PostHog Dashboards** se você só precisa de product analytics.

## Gotchas

- **N+1 em dashboard** = morte. Sempre `JOIN` ou `WITH cte`. Use `EXPLAIN ANALYZE`.
- **Index em colunas de timestamp** — `created_at` sem índice = full table scan.
- **Tooltip do Recharts em mobile** — touch não emite hover. Use click handler.
- **Cache invalidation** — define tags e invalida em writes (`revalidateTag('orders')`).
- **Authorization** — todo query precisa filtrar por `organizationId`. Esquece um, vaza.
