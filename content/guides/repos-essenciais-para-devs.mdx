GitHub tem 400 milhões de repos. Não é volume — é seleção. Esta lista são os repositórios que **devem estar nos seus favoritos** se você constrói coisas para a web em 2026.

## Templates / Starters

### [vercel/next.js](https://github.com/vercel/next.js)
O próprio Next. Issues e discussões aqui dizem o que está vindo antes da release.

### [shadcn-ui/ui](https://github.com/shadcn-ui/ui)
Não é só componentes — é o padrão de **registry**, que está virando default para distribuição de componentes copy-paste.

### [vercel/next-forge](https://github.com/vercel/next-forge)
Starter Turborepo de SaaS com Auth + Stripe + Email + Analytics + Observability. Forke, troque marca, deploy.

### [steven-tey/precedent](https://github.com/steven-tey/precedent)
Starter Next minimal mas com decisões opinionadas inteligentes. Boa fonte de "como faria certo".

### [t3-oss/create-t3-app](https://github.com/t3-oss/create-t3-app)
Stack tipada de ponta a ponta. Útil mesmo se você não usa o exato setup — código é referência.

## Listas curadas (awesome-*)

### [sindresorhus/awesome](https://github.com/sindresorhus/awesome)
A lista das listas. Ponto de entrada para qualquer domínio técnico.

### [public-apis/public-apis](https://github.com/public-apis/public-apis)
APIs gratuitas categorizadas. Salva horas em hackathon, prototipagem, MVP.

### [ripienaar/free-for-dev](https://github.com/ripienaar/free-for-dev)
Serviços com plano gratuito para devs. Antes de pagar por algo, cheque aqui.

### [tldr-pages/tldr](https://github.com/tldr-pages/tldr)
"Man pages para humanos". Exemplo prático de cada CLI em vez de árvore de flags.

### [trekhleb/javascript-algorithms](https://github.com/trekhleb/javascript-algorithms)
Algoritmos e estruturas em JS com explicação. Útil para entrevistas e fundamentos.

## Ferramentas que mudam dia a dia

### [biomejs/biome](https://github.com/biomejs/biome)
Linter + formatter substituindo ESLint + Prettier. 30x mais rápido. Em 2026 é default.

### [oven-sh/bun](https://github.com/oven-sh/bun)
Runtime + package manager + bundler. Cresceu em produção em 2025-2026.

### [unjs/h3](https://github.com/unjs/h3)
HTTP framework universal — funciona em Node, Bun, Workers, Deno. Powers Nitro/Nuxt.

### [drizzle-team/drizzle-orm](https://github.com/drizzle-team/drizzle-orm)
ORM TS-first. Veja issues fechadas — aprende muito SQL pelo padrão.

### [colinhacks/zod](https://github.com/colinhacks/zod)
Validação de schema. Virou infraestrutura — AI SDK, tRPC, Drizzle, tudo usa.

### [openobserve/openobserve](https://github.com/openobserve/openobserve)

## Como aproveitar essa lista

- **Não tente ler todos** — 50 repos numa lista é overwhelming
- **Star 5-10 dessa lista** que se conectam ao que você faz HOJE
- **Quando precisar resolver problema X**, volte aqui antes de googlear
- **Configure GitHub Notifications** para os repos que você usa em produção — vê issue/release antes do anúncio

A maior ROI de favoritar bons repos não é "ter a lista" — é **descobrir** padrões antes que virem mainstream e te custem migração.
