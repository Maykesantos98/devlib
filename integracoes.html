04

Conectar seu agente

Troque devlib.seudominio.com pelo domínio definitivo da VPS. A senha fica somente no cliente.

CC

Claude Code

Comando direto

claude mcp add --transport http devlib https://devlib.seudominio.com/mcp
CX

Codex

Configuração TOML

[mcp_servers.devlib]
url = "https://devlib.seudominio.com/mcp"
M

Clientes MCP

Cursor, VS Code e outros clientes com servidor HTTP remoto

{
  "mcpServers": {
    "devlib": {
      "type": "http",
      "url": "https://devlib.seudominio.com/mcp"
    }
  }
}
Segurança

O endpoint da VPS usa HTTPS e autenticação. Nunca coloque senha ou token em arquivo versionado; use o armazenamento seguro ou variável de ambiente do cliente.
